# TechService

TechService es una aplicación web en desarrollo para pequeños talleres de reparación de computadoras. Su objetivo es gestionar clientes, equipos y órdenes de trabajo, dar seguimiento a las reparaciones y consultar el historial de servicios.

El proyecto está en su etapa inicial: el repositorio contiene los documentos de diseño y la configuración básica. El backend con Python y FastAPI, el frontend con React y TypeScript y la persistencia con PostgreSQL están previstos, pero aún no están implementados. El siguiente paso es inicializar el backend y añadir el endpoint `/health`.

Las instrucciones de instalación y ejecución se añadirán cuando exista una aplicación y se hayan comprobado los pasos.

Documentación de diseño: [requisitos del MVP](docs/requirements.md), [arquitectura](docs/architecture.md), [modelo de datos](docs/data-model.md) y [contrato inicial de API](docs/api.md).
